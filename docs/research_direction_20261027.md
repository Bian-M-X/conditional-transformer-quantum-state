# 七轮之后：研究选题与下一阶段决策

2026-10-27 / Issue #17 / 面向 ICLR 级研究质量的路线评估

## 1. 决策：先检验预算决策是否可学，再投入新方法

建议主攻的候选问题是：**在训练态没有充分收敛、参数覆盖有限、投影矩阵还含采样噪声时，如何用少量且计费的探测，决定继续精修、增加锚点或重新采样？** 暂定题目为“条件神经量子态中训练、覆盖与估计精度的联合预算分配”。它是有条件推荐的研究问题，尚非已成立的新颖贡献。

七轮最有价值的积累，是可靠地暴露了“误差从哪里来尚不清楚”。已有工作不支持把共享训练、输入尺度、扩大覆盖或某一优化器当作普遍解释。继续组合这些技巧的信息收益有限。下一步应先检查：不同状态下真正值得执行的动作是否不同，低成本信息能否预测这种差异，以及扣除探测费用后是否还有收益。

这一问句也有直接先例：自适应降阶方法早已联合考虑快照精度与参数选择，量子子空间方法已有采样分配。潜在贡献只能来自非凸 NQS、错误低能分支与随机估计同时存在时的可辨识条件、决策机制和跨任务效果，不能来自重新命名三个动作。若简单既有策略已足够，就停止方法主张。

| 路线 | 本次决定 | 原因 |
|---|---|---|
| 条件 Transformer、缩放、协变、扩大区间 | 保留课程与控制身份 | 七轮没有给出稳定的新方法优势 |
| 再画共享与 Ritz 的成本交叉曲线 | 作为必要基线 | FNEH 已直接研究累计查询成本 |
| 联合精修、加点、重采样 | 有条件主攻 | 先验证动作价值与可学性，接受被旧方法否决 |
| 只换成低能子空间输出 | 不单独立题 | 多态变分与子空间优化已有明确先例 |
| 修正态的 Born 采样成本 | 备选专题 | 输出任务有差别，但须先查叠加态采样近邻 |

本次采用 academic-research-suite 的研究与来源核查流程，三个 Agent 分别做文献、物理反方和资源审计；这属于同一研究工具链，不是独立人类复现。本文中的 observed 是核验记录，derived 是条件推导，hypothesized 是待检验解释，planned 是后续工作。没有新增科学训练、GPU 训练或论文优势结果。

## 3. 文献把可主张的新意收紧到哪里

以下是定向的新颖性排查，不是穷尽式系统综述。实际阅读范围及版本逐篇列在[核验表](literature_direction_20261027.md)。未检索到完全相同的问题，不构成新颖性证明。

| 一手工作 | 已覆盖的问题 | 我们必须怎样区别 |
|---|---|---|
| [TQS](https://arxiv.org/html/2208.01758v4)、[FNQS](https://arxiv.org/html/2502.09488v3) | 多哈密顿量、参数泛化与微调 | 不以条件表示本身立题 |
| [FNEH](https://arxiv.org/html/2608.14208v1) | 神经训练态子空间、算符缓存、累计查询成本 | 成本曲线是基线，不是空白问题 |
| [Sarkar–Lee](https://arxiv.org/html/2107.13449v2) | 主动 EC 与误差代理 | 残差最大处加点不够；须检验不准锚点 |
| [自适应快照原稿](https://www.uni-ulm.de/fileadmin/website_uni_ulm/mawi2/dokumente/preprint-server/2014/1402_su-adap-20140505-submitted.pdf) | 重选旧参数并提高求解精度 | 联合精修与选点不是首次提出 |
| [FeynmanNet–EC](https://arxiv.org/html/2606.12998v3) | VMC非精确态、迁移、投影矩阵噪声 | 必须考虑重采样和稳定化，而非只加点 |
| [QSD理论](https://arxiv.org/abs/2110.07492)、[自适应测量](https://arxiv.org/abs/2311.07893) | 含噪广义本征问题、截断与测量分配 | 简单矩阵误差界或重采样亦非新方法 |
| [多态变分原理](https://arxiv.org/html/2504.21459v1)、[拓扑障碍](https://arxiv.org/html/2609.07591v1) | 学习低能子空间、纯态表示的拓扑边界 | 不能仅靠改成子空间或密度表示立题 |

FNEH 的 Fig.4e 已比较目标数增加时的实测时间；其特定设置约超过12个目标后出现相对 FNQS 的成本优势。这个数值属于该文设置，不能搬成本项目的阈值。2014年 Steih–Urban 原稿 §3.4、Eq.3.15 已在重复选中旧参数时收紧快照容差；它与后来 Ali–Steih–Urban 修订版的具体策略需要区分。

两个潜在区别值得检验，而非直接宣布成立：第一，稳定 PDE 快照求解器的误差控制假设不适用于非凸 NQS 的错误本征态；第二，锚点优化、跨参数覆盖和投影估计互相耦合，单独优化其中一项可能浪费预算。ICLR 级贡献须证明这一差别确实产生了新机制与可复用方法，应用场景换名不足以成立。

物理边界同样重要：[边界场 Ising 研究](https://arxiv.org/abs/1507.08391)通过辅助自旋和费米子化处理边界纵场。因此现有 lambda Z1 扩展仍应作为可解性控制族；加入边界场不自动成为一般强关联难题。1D MPS/DMRG 是必要强基线，理想猫态只需 bond dimension 2。

## 4. 实验条件决定了怎样推进

observed：本机32逻辑CPU、物理内存63.68 GiB；nvidia-smi 显示 RTX 5000 Ada Laptop、约16 GiB显存。当前环境 torch2.14.1+cpu，CUDA不可用，现有 runner 明确使用CPU。GPU存在不等于GPU训练已经打通；本次没有改变依赖或做CUDA训练。

工程微基准在CPU单线程、float64、窄Transformer上测量，热身后各三次取中位数。核计时使用重复的实际 Jacobian 构成合成三条件矩阵，仅反映算子成本。完整代码正文与原始输出归档在[资源证据](results/direction_20261027/resource_audit.json)；整理后的调度包装本次未执行，时间不保证可逐值复现。

内存表由维度公式推算，不是实际分配测试。N=8/10 的机制验证现在即可用CPU完成；N≥14不应继续按当前稠密实现放大。GPU采样式 N=16/24 仅作为后续性能先导目标，须另测显存、吞吐和误差，当前没有可训练性证据。

必须先补三个工程条件：矩阵自由/稀疏 H 作用；可恢复的模型、优化器、RNG检查点；真实自回归采样和MC矩阵估计。当前历史哈希与振幅不足以从任意训练步继续优化。CPU/GPU迁移还涉及张量设备、评估回CPU和数值一致性，不能只换一个安装包。

尤其应修正成本基线：当前 ritz 每个查询重复 SVD 和全维投影。仿射 H 应一次缓存 Q 与 Q^T H_j Q，观测量缓存 Q^T O Q；在线只解小矩阵。完整振幅重构是ED评估或特定输出任务的开销，不能默认算进只查询能量的部署成本。

## 5. 主问题、允许的信息与潜在贡献

给定哈密顿量族 H(x)、查询分布和固定总预算，维护一组近似神经态及其投影估计。每轮可执行三类动作：R，继续优化或重启某个旧锚点；A，在新参数处训练并扩充基底；M，为已有重叠/算符矩阵增加采样。共享网络可以作为初始化或对照，但候选方向不要求 Transformer 必须取胜。

候选策略可读取训练能量、梯度或残差代理、Gram谱、矩阵估计的不确定性，以及少量计费干预后的变化。不得读取测试精确态、真实能隙、ED动作排名，也不得按这些量选择部署checkpoint。若只在精确全枚举设置测试，M没有统计噪声可消除，不能称为验证了三动作问题。

首先要回答可证伪的两问：预算有限时，最优动作是否随误差来源而改变？只使用允许信息，是否能在全成本下作出比固定比例、纯精修、纯加点及旧自适应快照策略更好的选择？若探测费用吃掉收益，研究应当停止，而不是先训练复杂强化学习控制器。

潜在的论文贡献应同时具有：明确的信息/任务模型；经过先例对照的决策机制或有用理论；自然训练场景中的必要性；跨尺寸、跨家族和含噪采样中的净收益。把三个已知动作拼到菜单里，只能算工程实现。

理论上有三条必须遵守的边界。错误激发态可以同时有零方差和零能量梯度，因此这些摘要不能认证基态。仅用旧态摘要区分动作价值存在反例，但哈密顿量已完整给出的模型与“只准探测 Hpsi”的受限模型不同，不能将后者的不可能性夸大。已测候选的二维 Ritz 降能可直接计算，但它只认证变分能量改善。

含噪子空间还有标准稳定性约束：若真实Gram的最小特征值为sigma，矩阵误差满足eta_S<sigma，则广义Rayleigh商扰动可由 (eta_H+M eta_S)/(sigma-eta_S) 控制，其中M是能量绝对值上界。这是已有矩阵扰动思路，不是新定理；重要性在于说明加点导致病态时可能应先重采样或截断。采样比值可能无界，不能未经假设就套有限样本置信界。

## 6. 下一次实验的门槛与停止规则

下面是待冻结的设计建议，不是已执行实验或正式预注册；新Issue应在数据生成前提交全部配置。建议用两周作为第一阶段的投入上限，不把它当成用户已承诺的工期或论文完成日期。

第一关：新颖性。逐条比较自适应快照精度、Sarkar–Lee、VMC–EC、FNEH/DSS、QSD稳定化和自适应矩阵测量。若拟议规则等价于旧点重选后加预算，或只重做已知矩阵误差界，就不进入方法开发。

第二关：实现与可学性。N=6只作代码开发；在N=8生成先导决策状态，完整保存检查点，分别短跑R/A/M反事实动作。ED收益与遗憾标签仅作事后分析；若训练调度器，主线只用可计算变分收益，另分训练、验证和从未访问的测试任务。使用ED标签的支线只能称oracle监督基线。自然失败与人为扰动分别报告，后者不能单独支持价值。

第三关：验证。先导完成后才冻结 N=10、新参数与新种子；每任务至少五个配对种子。保留当前链作解析控制，另加入一种确实超出其自由费米子结构、仍适合正实态的家族，例如两腿TFIM梯形格；参考解须经稀疏ED/MPS收敛核查。更大采样任务须在接口和性能检查通过后另行冻结。

| 必须比较的策略 | 它排除的解释 |
|---|---|
| 固定总预算比例、纯R、纯A、纯M | 仅因多做计算或挑弱基线获胜 |
| 重选旧点式自适应快照、主动EC | 仅复现已知覆盖/精度策略 |
| 强单点优化、warm start/微调 | 锚点只是没有认真训练 |
| 缓存仿射EC、FNEH式基底/DSS、噪声截断 | 故意做慢或做不稳子空间基线 |
| MPS与可解参考 | 把1D易处理控制族误称一般难题 |

主评价建议是：达到事前指定态/观测误差所需的同硬件总时间，以及固定预算结束时的错误与失败率；探测、预训练、调度器训练、矩阵刷新、无效缓存与最终查询全部计入。H作用、Jacobian行、网络调用是不同单位，分别记录，不直接相加冒充算力。ED只按固定检查时刻事后评分，不能替算法停止。

建议进入后续大实验的操作门槛：在两个保留任务族、至少4/5种子中，达到共同预设精度的总时间较最强对照减少至少20%，且无未披露的精度恶化；或同预算误差达到预先约定的实质下降。20%是未来投入门槛，不是已观察效果或显著性保证。实际精度、删失失败处理和唯一主指标必须在先导之后、验证之前冻结；不能看到验证结果后在时间和误差间择优。

## 7. 备选方向与 ICLR 级证据要求

备选是“子空间修正态的采样可靠性与真实输出成本”。能量/观测量扫描只需要小投影矩阵；产生修正态的独立 Born 样本则是另一个任务。原自回归态的线性组合通常不再直接祖先采样，但这不等于无法采样。

derived：对归一化态psi_i、系数c_i，令C=sum|c_i|，以权重|c_i|/C混合原分布作为q。加权Cauchy给出 |sum c_i psi_i|^2<=C^2 q，因此可拒绝采样；平均接受率是 c^* S c/C^2。消干涉或近线性相关可能增加开销。该公式只是已知构件的初等推导，尚无新颖性主张；它必须先成为基线，才能讨论新采样方法。

even 控制也不应因实现缺失被排除。当前正实psi可用原分布和翻转分布的等权混合提议，接受概率为 (psi(s)+psi(Ps))^2/[2(p(s)+p(Ps))]，平均接受率至少1/2。仓库尚未实现该采样器，但这条可行性说明“大尺度不能比较even”不是充分理由。

这个备选应先检查原采样与混合拒绝采样已经是否足够快；若只需少量拒绝，就没有必要再做蒸馏或新网络。如果它需要偏离原题太多的软件开发，优先保留主方向的判别实验。

ICLR 级目标不是再增加一轮编号，而是形成别人能够审查的贡献链：明确且未被近邻覆盖的问题、能解释何时有效的机制、超过强基线的跨任务净收益、合适的规模与采样条件、完整复现和独立核查。N=8/10只是机制验证门槛；仅这些规模通常不足以支撑广泛的可扩展方法主张。GPU条件不支持继续扩展时，应缩小论文主张而非夸大规模。

课程交付继续使用第七轮及原题对照；新选题不承担重新证明课程要求的任务。当前主线失败时，七轮负面证据仍可形成有价值的基准/方法学记录，但不会因此自动达到 ICLR 主会质量。最终建议是：先投入一个有明确否决条件的预算决策先导；通过后才写方法论文的主叙事。
