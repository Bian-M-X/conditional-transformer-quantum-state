研究问句：在不查询待预测基态真值的条件下，如何选择哈密顿量参数进行训练，使条件 NQS 在有限计算预算和近简并区域中获得可复现的泛化表现？

## 当前模型与重要机制

基准族：`H(h, λ) = -Σ_{i=1}^{N-1} Z_i Z_{i+1} - h Σ_i X_i + λ Z_1`，开放边界，`h≥0`。`λ=0` 时全局 `P=∏X_i` 与 `H` 对易；非零 `λ` 一般破坏该宇称对称性。

低能两态近似在一定条件下给出尺度 `λ_c = Δ / (2|<+|Z_1|->|)`；该量使用了低能谱信息，**不允许未经标注直接用在声称无 oracle 的主动采样算法中**。
